### 小程序简介（用于资料页，300 字以内）
```
「申归途」是一款面向抑郁症康复期人群的复发预防支持工具。

核心功能：
· 每日签到：睡眠、情绪、身体活力、动力、思维、社交六维度评分，生成综合风险指数与 7 天趋势；
· 用药管理：服药打卡、30 天依从率、连续天数统计、药物起效期引导、常用药物知识库；
· 副作用周报：每周记录身体反应，自动生成可复制给医生的复诊报告与循证应对建议；
· 减药导航：在医生指导下的分阶段减药计划与进度报告；
· 心理课程：CBT、MBCT、WRAP、ACT 三层共 12 门循证课程，含呼吸、身体扫描等引导练习；
· 服务中心：上海地区精神科医院、24 小时心理热线、社区资源、医保政策检索；
· 家属支持：家属教育课程、分级行动指南、照护者压力自评；
· 危机干预：一键拨打官方心理热线，4-7-8 呼吸放松练习，安全提示。

本工具仅作自我管理辅助，不提供医疗诊断与处方，所有数据仅保存在用户手机本地。
```

## 二、服务类目与资质建议

| 优先级 | 类目选择 | 说明 |
|---|---|---|
| 首选 | 工具 > 效率 或 工具 > 信息查询 | 以「自我管理工具」定位申报，规避医疗资质门槛 |
| 备选 | 教育学习 > 在线教育（非学科类） | 若审核关注课程属性，可补报此类目 |

注意事项：
1. 个人主体无法开通「医疗健康」类目；即使企业主体，此类目需医疗机构执业许可，不建议硬报。
2. 全部页面已带免责声明（「不替代专业医疗建议」），危机页仅引导拨打官方热线，不提供诊断咨询——这是按工具类目过审的关键话术。
3. 若首次提审被驳回并要求选择医疗类目，可先删减提审版本中的「用药知识库/减药导航」入口（页面保留但不在首页突出），以工具属性提交，后续按需迭代。

## 三、审核备注模板（提交审核时粘贴到「审核备注」）

```
本小程序为心理健康自我管理辅助工具（工具-效率类目），核心逻辑如下：

1. 功能定位：帮助用户做日常状态记录、用药打卡与康复知识学习，不提供任何医疗诊断、治疗建议、处方或在线问诊服务；不含医院挂号、问诊、购药等医疗交易功能。

2. 数据安全：用户全部数据仅通过本地缓存（wx.setStorageSync）存储于用户本人手机，不收集、不上传任何用户信息；未接入任何后端服务器。

3. 内容来源：医院/热线/医保信息为公开信息整理，课程内容基于公开的循证心理学方法（CBT/MBCT/WRAP/ACT）整理，页面均标注「不替代专业医疗建议」。

4. 危机场景处理：页面不提供任何心理咨询服务，仅在危机干预页引导用户拨打官方公益心理热线 962525 与急救 120（使用 wx.makePhoneCall 拨号能力）。

5. 测试方式：打开即用，无登录、无支付、无社交发布功能。建议按底部导航依次浏览：首页→疗愈→服务→成长。
```

## 五、视频预览脚本（30–40 秒，mp4 ≤ 20MB）

| 时间 | 画面 | 操作 |
|---|---|---|
| 0–4s | 欢迎页 | 点击「开始使用」进入首页 |
| 4–10s | 预警仪表盘 | 停留展示评分环与趋势图，点击「开始今日签到」 |
| 10–16s | 每日签到 | 逐维评分 → 提交，展示成功页 |
| 16–23s | 疗愈 tab | 服药打卡 → 进入副作用周报提交一次 → 展示应对策略页 |
| 23–30s | 危机页 | 点悬浮按钮进入，展示热线按钮与呼吸练习动画 |
| 30–38s | 成长 tab | 打开一门课程 → 播放引导练习，展示呼吸圆环动画后结束 |

录制：真机预览 + 系统录屏；iPhone 的 mov 用 QuickTime 或 `ffmpeg -i in.mov -vcodec h264 out.mp4` 转 mp4。
