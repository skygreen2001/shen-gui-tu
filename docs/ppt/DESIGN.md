# 申归途 · 路演分享材料｜设计说明

## Step 1 需求对齐

| 维度 | 结论 |
|---|---|
| 主题 | 「申归途」抑郁症全程复发预防服务 · 参赛作品路演 |
| 场合 | 「AI 无限职场」SOLO 挑战赛 · Hello AI 科技致善 公益赛道，活动现场上台分享 |
| 目标 | 让评委在 12–15 分钟内相信：痛点真实、方案循证、作品已落地、SOLO 过程可复现 |
| 受众 | 赛事评委 + 现场开发者 / 公益向观众 |
| 页数 | 24 页（用户要求 25 页以内） |
| 调性 | 克制、有温度、不煽情；与产品本身的「低刺激」伦理一致 |

## 全局视觉约定

### 画布与安全区
1280×720；padding 上下 60 / 左右 60；内容区 1160×600。页脚固定 y≈670，封面 / 结尾不加页尾。

### 字体
中文 `Microsoft YaHei`（雅黑），西文 `Helvetica Neue, Arial`。全篇仅此一组。
字号阶梯：封面主标 84 / 巨型数据 96 / 页面主标 34 / 卡片小标 22 / 正文 19 / 注释 14。
同页样式组合 ≤ 4 种；正文 ≥ 18px；注释 ≥ 14px。

### 视觉母题
① 页面主标题下方 1px 贯通细线 `#E3DCD2`；② 左上角统一章节眉标（14px 主色小字）；③ 页脚左「申归途 · 路演分享」右页码，位置全篇固定；④ 从左下到右上的「归途弧线」作为封面与结尾的图形呼应。

### 事实口径（全部来自 docs 目录材料）
- 9,500 万患者 / 就诊率不足 30% / 充分治疗率不足 1% / 首次就医延迟 2.1 年 / 精神科医生 6.4 万人
- 复发率 50%–85%；首次复发后再复发 >70%；三次发作后 90%
- 50% 依从性问题、47% 不了解所服药品、仅 9% 了解减药方法
- 六维预警：睡眠 / 情绪 / 躯体 / 动力 / 认知 / 社交；睡眠最早期最敏感
- 四阶段旅程：过渡期 0–4 周、巩固期 1–6 月、维持期 6–18 月、自立期 18 月+
- 六大模块：预警监测 / 用药管理 / 数字心理干预 / 社会支持 / 照护者支持 / WRAP 计划
- 产品实测：React 18 + Vite 5 + CSS Modules + LocalStorage；12 门课程（4+5+3）；上海 10 家医院 / 6 条热线 / 4 个社区中心 / 5 项医保政策；热线 962525、400-161-9995
- 两轮 dogfood：55 用例 → 48 通过 4 失败 3 待验证；第二轮 10 页面全 PASS、0 高/中优先级问题；总体完成度 ~45% → ~90%
- SOLO 过程：20 分钟任务拆解 → 2 小时可交互原型 → 3 天打磨
