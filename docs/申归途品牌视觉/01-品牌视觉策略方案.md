# 申归途 · 品牌视觉方向与情绪板策略方案

> 产品：申归途 | 抑郁症全程复发预防服务（移动端 Web App）
> 版本：v1.0 | 创意策略：策凌 Celine
> 本文档为策略层输出，不产出成图；第 7 章的 Prompt 供 image-creator 直接执行。

---

## 0. 前言：这份方案要解决的唯一难题

申归途不是又一个健康 App。它的用户是**已经从最黑暗的地方走出来、但随时可能再掉回去的人**。这决定了它的视觉设计有一个反常识的前提：

> **我们不是在"激励"用户，我们是在"不打扰地托住"用户。**

一个康复期患者打开 App 的那一刻，可能正处于：注意力涣散、自责、对数字极度敏感、连点开第二个页面都费力。此时任何"红色数字 + 感叹号 + 弹窗"，都不是预警，而是**伤害**。

因此本方案的所有视觉决策都服从一条元规则：

```
低刺激 > 高唤醒
可预期 > 有惊喜
有出口 > 有警示
陪伴者 > 管理者
```

## 1. 品牌定位核心（Brand Core）

### 1.1 一句话品牌主张

> **「出院不是结束，是归途的开始。」**

英文辅助：`The road home starts here.`

**主张推导逻辑**：
- "出院"锚定用户所处真实时点（产品切入的是出院后断崖式空白）
- "不是结束"否定了"治好了就完了"的错误认知，也否定了"又复发了就完了"的灾难化思维
- "归途"同时承载三重含义：康复之路 / 回家的路 / 上海（申）的在地性
- "开始"是唯一的动词，克制、不煽动

**备选主张（供 A/B 或不同投放位使用）**：

| 场景 | 备选主张 |
|------|---------|
| 医院/社区渠道物料 | 复发可防，归途有光 |
| App 首屏欢迎语 | 回家这条路，我们一起走 |
| 危机干预页 | 你现在不是一个人 |

### 1.2 目标用户画像

**主力用户：康复期患者**

| 维度 | 描述 |
|------|------|
| 年龄 | 18–45 岁为主（学生 / 职场 / 新手父母） |
| 临床阶段 | 抑郁症临床缓解期或部分缓解期；已出院，或门诊稳定随访中 |
| 用药状态 | 维持期服药，或正在医生指导下减量（最易复发的窗口） |
| 数字能力 | 熟练使用智能手机，但对"复杂表单 / 多层级导航"耐受度低 |
| 核心恐惧 | "我是不是又要回去了"；被判定为"又病了"；成为家人负担 |

**次要用户：照护者 / 家属**
- 年龄 35–60 岁，多为父母或配偶
- 诉求：想知道"今天他怎么样"，但不想越界变成监视
- 设计含义：若未来做家属端，视觉需与患者端做明确区分（避免"被监控"感）

**五大典型使用场景与情绪状态**（直接决定 UI 设计）：

| # | 场景 | 时间 | 情绪状态 | 设计含义 |
|---|------|------|---------|---------|
| S1 | 醒来第一眼 | 早晨 7–9 点 | 低动力、迟钝、可能不想起床 | 首屏必须"一眼看完"，签到 ≤30 秒，绝不多层级 |
| S2 | 想停药的自我怀疑 | 任意时刻 | 焦虑、侥幸、羞耻 | 用药页避免"你漏服了 X 天"式指责，改为"已坚持 X 天" |
| S3 | 疑似复发信号出现 | 傍晚/夜间 | 恐慌、灾难化 | 风险提示必须**同屏给出口**，绝不留孤立红色数字 |
| S4 | 睡前回顾 | 22–24 点 | 疲惫、易自责 | 暗色模式必须暖调，禁止纯黑 #000 与高对比白字 |
| S5 | 复诊前整理 | 复诊前 1–2 天 | 需要条理、想和医生有效沟通 | 数据视图要"可导出/可讲清楚"，专业感在此刻最重要 |

### 1.3 品牌个性关键词（5 个）

每一个词都给出"是 / 不是"的边界——这是防止设计跑偏的最有效工具。

| # | 关键词 | **是**什么 | **不是**什么 |
|---|--------|-----------|-------------|
| 1 | **稳定 Steady** | 可预期的节奏、不惊扰、界面布局十年如一日、风险提示语气恒定 | 冷冰冰、机械、无感情的自动回复 |
| 2 | **温和 Gentle** | 低音量、留余地、允许"今天什么都不做"、允许空白和跳过 | 幼稚化、可爱化、哄小孩、"加油鸭" |
| 3 | **可信 Credible** | 临床循证、数据有出处、医院/热线信息准确可核、评分逻辑可解释 | 权威压制、诊断口吻、"系统判定你为重度" |
| 4 | **在地 Rooted** | 上海的具体街道、具体医院、具体号码、具体医保政策 | 空泛的关怀话术、"全国通用"的塑料温情 |
| 5 | **有光 Luminous** | 承认暗还在，但光已经在；方向感、微弱但持续的光源 | 强行乐观、"你一定可以"、"战胜抑郁" |

> **一句话串起来**：申归途像一个**每天早上在你家楼下等你的老朋友**——不催促你，不说教，但确实在，且知道附近哪家医院今天有号。

### 1.4 品牌语气（Tone of Voice）

**语气总纲**：陈述事实 + 提供出口 + 不评价人格。

**四条硬规则**：
1. **主语是"情况"，不是"你"** —— 说"睡眠这一项这几天有些波动"，不说"你最近睡眠很差"
2. **永远给下一步** —— 任何告知状态的话术，后面必须跟一个可执行的动作
3. **不用感叹号**（危机干预页除外，且最多一个）
4. **不承诺结果** —— 不说"坚持用药就不会复发"，说"规律服药是目前证据最充分的复发保护因素之一"

**正面示例 vs 禁忌示例**：

| 场景 | ✅ 正面示例 | ❌ 禁忌示例 | 为什么 |
|------|-----------|-----------|--------|
| 风险等级 L4 | 「这一周有几个维度在提醒我们，需要多一些人支持。你可以先做一次呼吸练习，或直接联系你的医生。」 | 「⚠️ 高危预警！你的抑郁正在复发！」 | 前者给出口，后者制造灾难化恐慌 |
| 漏服药物 | 「昨天的一次服药还没记录，补上就好。」 | 「你已连续漏服 1 天，依从率下降至 83%！」 | 前者不指责，后者制造羞耻 |
| 依从率展示 | 「这个月你有 26 天按时服药了。」 | 「依从率 86.7%，未达标（目标 ≥95%）」 | 前者正向表述，后者用 KPI 考核病人 |
| 签到未完成 | 「今天还没记录，随时可以补。也可以跳过。」 | 「打卡失败，连续天数已清零！🔥」 | 前者允许中断，后者用损失厌恶施压 |
| 连续签到 | 「你已经记录了 12 天。中断也没关系，随时可以重新开始。」 | 「🔥 连续签到 12 天！再断就前功尽弃！」 | 前者消解中断焦虑，后者制造焦虑 |
| 危机干预 | 「如果现在很难受，可以打这个电话，有人会接。」 | 「紧急情况！立即求助！」 | 前者平静可依靠，后者加剧惊恐 |
| CBT 课程 | 「第 3 步 / 共 5 步 · 大约需要 6 分钟」 | 「挑战自我，突破认知扭曲！」 | 前者降低认知负荷，后者高唤醒说教 |
| 空状态 | 「这里还空着。不着急，想写的时候再写。」 | 「快来完善你的康复计划吧～」 | 前者允许低能量状态，后者催促 |

**绝对禁用词库**（写入产品词库黑名单）：
`战胜 / 击败 / 斗争 / 抗争 / 康复率 100% / 你一定行 / 加油 / 前功尽弃 / 失败 / 未达标 / 高危 / 危险 / 复发警报 / 病情恶化 / 你必须 / 建议立即`

## 2. 三个视觉方向候选

> 三个方向均已按"低刺激、低认知负荷、去病耻感"为前提设计，差异在于**气质权重**不同。

---

### 方向 A ｜ 晨光归途（Morning Light · The Way Home）

**一句话概念**：清晨六点半，光刚起来，路是暖的——你已经在路上了。

**情绪关键词**：`微光`、`清晨`、`缓慢`、`温热`、`开阔`、`呼吸`

#### 色彩系统

| 角色 | 名称 | HEX | 说明 |
|------|------|-----|------|
| 主色 | 晨砂褐 Warm Clay | `#A97C5F` | 关键交互、选中态、品牌标识主色。低饱和暖褐，有"体温" |
| 主色-深 | 深砂褐 | `#8A6249` | 主色按压态 / 深色文字强调 |
| 辅色 | 微光橙 Soft Amber | `#E8A87C` | **仅小面积**：光的意象、进度填充、鼓励反馈 |
| 辅色-冷 | 静水青 Muted Teal | `#7C9A92` | 数据第二序列、冷静类信息（如服药记录） |
| 背景 | 暖砂白 | `#FAF7F2` | **核心决策**：绝不用纯白 #FFFFFF |
| 卡片 | 浅砂 | `#F2EDE6` | 卡片/容器底面 |
| 分隔 | 砂线 | `#E3DCD2` | 1px 分隔线 |
| 主文字 | 暖炭黑 | `#3A342E` | 正文标题，绝不用纯黑 #000 |
| 次文字 | 暖灰褐 | `#6E665C` | 说明性文字 |
| 弱文字 | 浅褐灰 | `#9A9188` | 占位/时间戳 |

#### ⚠️ 四级风险配色方案（本方案核心）

**设计难点**：产品必须显示四级风险分级，但绝不能让康复期患者因一个红色数字而恐慌。

**六条解决原则**（适用于所有方向）：

1. **拒绝纯色相红。** 最高级不使用 `#E03A2F` / `#FF3B30` 类"警报红/血红"。改用**降饱和 + 降明度**的陶土粉褐，视觉上是"暖的、重的"，不是"刺的、血的"。
2. **四级靠明度与饱和度递进，不靠色相跳变。** 色相沿暖调连续推移（`青绿 → 麦黄 → 蜜橙 → 陶土`），读起来像"光线逐渐变浓"，而不是"红绿灯跳到红灯"。这从认知上消解了"通过/不通过"的二元判定感。
3. **面积严格控制。** 风险色**永远不做大面积背景**，只出现在四种位置：状态圆点（8–12px）、细进度条填充、图标描边、卡片左侧 3px 竖条。大面积永远是中性暖白。
4. **形状 + 文字优先于颜色。** 每一级配不同**形状编码**（○ 实心圆 / ◎ 圆环 / △ 描边三角 / ◐ 半填充圆），文字命名用"稳定 / 留意 / 关注 / 需要支持"。颜色只是第三重编码，色觉障碍用户完全可用。
5. **禁止任何警示性动效。** 不做闪烁、脉动、抖动、弹窗跳脱、红色呼吸。四级状态切换用 400ms 交叉淡入。**全局唯一允许的"呼吸动效"是呼吸练习页面的圆**。
6. **出口优先（Exit-first）。** 任何风险色出现的同屏，必须有一个可见的"下一步"入口（呼吸练习 / 联系医生 / 热线 / 加一笔记）。把焦虑在 3 秒内导向行动。

**四级色值表（方向 A）**：

| 等级 | 名称 | 圆点色 | 文字色 | 浅底 | 形状编码 | 语义 |
|------|------|--------|--------|------|---------|------|
| L1 | 稳定 | `#7C9A92` | `#5E7A73` | `#EAF0EE` | ○ 实心圆 | 保持现在就好 |
| L2 | 留意 | `#C7A96B` | `#9A8248` | `#F5EFE0` | ◎ 圆环 | 有一项在波动，看一眼 |
| L3 | 关注 | `#D08F63` | `#A96C42` | `#F7EBE0` | △ 描边三角 | 需要多留意几天 |
| L4 | 需要支持 | `#B96B5C` | `#944F42` | `#F6E5E1` | ◐ 半填充圆 | 联系医生或信任的人 |

> **对比度校验**：L4 文字色 `#944F42` 在浅底 `#F6E5E1` 上对比度约 5.4:1，满足 WCAG AA 正文标准；所有四级文字色在暖砂白 `#FAF7F2` 上均 ≥ 4.5:1。
>
> **色觉友好**：四级明度阶梯为 L1(61%) → L2(68%) → L3(64%) → L4(52%)，配合形状编码与文字，红绿色盲用户可完全区分。设置中另提供「高对比模式」开关，切换为纯明度阶梯（浅灰 → 深炭）。

**危机干预按钮色（特别说明）**：
传统做法是红色大按钮。本方案建议主色用**深静水青 `#3F5C63`** 或**深砂褐 `#8A6249`**，理由：红色按钮在平静浏览时是持续的低度威胁信号，长期暴露会提高基础焦虑水平。危机按钮的"紧急感"应通过**尺寸（最大）、位置（固定底栏）、文案（"现在打这个电话"）**实现，而不是颜色。

> 若临床顾问坚持红色，折中方案：按钮常态为深静水青，仅在用户主动点击"我现在很危险"后，界面整体降饱和 + 显示热线，仍不使用红色。

#### 字体方向

| 层级 | 方向 | 气质 | 规格 |
|------|------|------|------|
| 中文标题 | 中性人文无衬线（思源黑体 / 苹方 / HarmonyOS Sans 一类） | 安静、不抢戏、略带圆润收笔 | 20–24px / Medium(500) / 行高 1.5 |
| 中文正文 | 同上 | 清爽、易读 | 15–16px / Regular(400) / 行高 **1.75** / 字距 +0.02em |
| 数字/评分 | 人文本无衬线 + 等宽数字（tabular figures） | 稳定、不对齐抖动 | 评分主数字 44–56px / Light(300)–Regular |
| 英文/字母 | 几何人文无衬线（Inter / Söhne 一类开阔字形） | 中性、国际化 | 与中文基线对齐 |

**字体禁忌**：
- ❌ 正文用宋体/衬线体 → 立刻产生"病历 / 通知书"的机构压迫感
- ❌ 极细字重（100/200）做正文 → 低能量状态下阅读困难
- ❌ 全大写英文 → 视觉上等于"在喊"
- ❌ Bold 做长标题 → 重量压人
- ✅ 行高至少 1.75，字距略放宽——这是"呼吸感"最廉价也最有效的来源

#### 图形语言

- **圆角**：卡片 20px（大容器）/ 12px（按钮、输入）/ 8px（小标签）。整体偏"柔软容器"，避免锐角
- **形状**：有机曲线、非闭合弧线、"路径"意象（一条从左下到右上的缓弧，是全局图形母题）
- **线条**：1.5px 描边为主，图标 2px，**圆头端点（round cap）**，视觉重量统一
- **图标**：线性描边风格，禁止实心 emoji 化图标；同一屏内图标描边粗细必须一致
- **留白节奏**：屏幕边距 20px，卡片内边距 20–24px，模块间距 16–20px。**一屏最多 3 个信息块**，超出即折叠
- **阴影**：几乎不用投影。使用 `1px #E3DCD2 描边 + 0 2px 8px rgba(58,52,46,0.04)` 的极弱"浮起"
- **网格**：8pt 基准网格，所有间距为 8 的倍数

#### 图像 / 插画风格

- **媒介**：抽象化的风景摄影为主（占 80%），极简静物为辅
- **题材**：清晨或黄昏的柔光、上海城市远景剪影、窗光与窗帘、空旷的路、水面反光、树叶透光、梧桐树影
- **处理**：高光柔和溢出（soft bloom）、低对比、轻微雾化、细腻颗粒
- **人物规则**：**绝不出现清晰面部**。可出现手部、背影、鞋、远处模糊人影（且必须"结伴"不"独行"）
- **禁忌题材**：深渊、坠落、锁链、笼子、暴雨、乌云、枯树、空椅子、迷宫、破碎的镜子

#### 材质与肌理

- **纸张颗粒**：全局叠加 3–5% 细噪点（降低"数码屏"的冷硬感，提升"可触摸"的安心感）
- **光线渐层**：暖白 → 浅金的径向渐变作为背景光晕，透明度 ≤ 8%，永远不抢内容
- **磨砂玻璃**：仅用于顶部导航（background-blur + 6% 暖白遮罩），不做重度玻璃拟态
- **禁忌**：高光塑料感、强反光、霓虹渐变、金属质感、强对比玻璃拟态

#### 动效调性

| 参数 | 值 | 说明 |
|------|-----|------|
| 进场时长 | 240ms | 页面/卡片进入 |
| 反馈时长 | 140ms | 点击、选中 |
| 状态切换 | 400ms 交叉淡入 | 风险等级变化，绝不闪 |
| 缓动 | `cubic-bezier(0.22, 0.61, 0.36, 1)` | 偏软的 ease-out |
| 位移 | 8–12px | 进场位移极小，避免"飞来飞去" |

- **全局唯一装饰动效**：呼吸练习页面的圆，8 秒周期慢速缩放（4s 吸 / 7s 屏 / 8s 呼的 4-7-8 节奏可视化）
- **禁止**：弹跳（bounce）、overshoot、抖动、自动轮播、无限循环加载动画、粒子效果、任何闪烁

#### 优势与风险

**优势**
- 暖调在低能量状态下最安全：冷灰蓝会强化情绪低落，暖砂褐提供"体温感"
- `#FAF7F2` 暖砂白直接解决"纯白屏幕刺眼"问题（抑郁患者常见光敏感）
- 晨光是唯一同时表达"暗还在"和"光已来"的意象——不否认痛苦，也不沉溺痛苦
- "路 + 光 + 上海早晨"与品牌名"归途"天然同构，叙事成本极低

**风险**
- ⚠️ 过于素淡可能让用户（及医院合作方）质疑临床专业性 → **缓解**：在数据视图、服务中心、CBT 课程页引入 B 方向的秩序感与信息密度
- ⚠️ 暖褐色在暗色模式下较难处理（易显浑浊）→ **缓解**：暗色模式不用纯黑，用 `#26221E` 暖深底，主色提亮至 `#C99A7A`
- ⚠️ 光线意象做得过"文艺"会显得与实际功能脱节 → **缓解**：摄影素材只用于空状态、欢迎页、课程头图，功能页一律纯色 + 数据可视化

### 方向 B ｜ 静水（Still Water · Clinical Calm）

**情绪关键词**：`澄澈`、`安静`、`秩序`、`专业`、`精确`、`托底`

#### 色彩系统

#### ⚠️ 四级风险配色（方向 B）

采用**莫兰迪式低饱和序列**，色相从青 → 蓝灰 → 藕灰 → 陶土缓慢推移，四级饱和度全部控制在 20–30%，整体极度柔和：

| 等级 | 名称 | 圆点色 | 文字色 | 浅底 | 形状 |
|------|------|--------|--------|------|------|
| L1 | 稳定 | `#7FA3A0` | `#5C7D7A` | `#EAF0EF` | ○ |
| L2 | 留意 | `#93A3B0` | `#6B7D8C` | `#EDF1F3` | ◎ |
| L3 | 关注 | `#AD9A96` | `#826C68` | `#F3EDEC` | △ |
| L4 | 需要支持 | `#B98C80` | `#8E6558` | `#F5EBE7` | ◐ |

> B 方向分级更"冷"，四级间的色相差更小、辨识度略低 → 因此**形状编码与文字在 B 方向是强制性的**，颜色退为辅助。

#### 字体方向

- 中性无衬线，几何感略强（Inter / HarmonyOS Sans 一类）
- **字重对比清晰**：400 / 500 / 600 三档，用于建立信息层级
- 数字强制 `tabular-nums`（等宽数字），保证趋势图与列表对齐
- 行高 1.6（比 A 略紧），信息密度更高
- 标题克制：不加粗、不放大，靠字重 500 + 字号 20px 建立层级

#### 图形语言

- 中小圆角（8–12px），直角与圆角混用（按钮圆角，数据卡片直角）
- 严格 8pt 网格，对齐精度要求最高
- 图标线性 1.75px，**直角端点（butt cap）**——与 A 的圆头形成对比，更"仪器感"
- 留白紧凑：卡片内边距 16px，模块间距 12px，一屏可容纳 4–5 个信息块
- 阴影：无，靠 1px 描边分隔

#### 图像 / 插画风格

- **几乎不用摄影**。主视觉由**抽象几何 + 数据可视化**构成
- 偶用极简静物摄影（一杯静置的水、窗、白纸、刻度）
- 无插画、无人物、无装饰图形
- 视觉重点全部让给：折线图、环形进度、六维雷达、数字

#### 材质与肌理

- 纯色为主，极低对比渐层（≤5%）
- **无噪点**（保持"洁净"感）
- 玻璃拟态极轻或不用
- 表面质感："磨砂亚光"，无反光

#### 动效调性

- 时长 150–250ms，标准缓动 `cubic-bezier(0.4, 0, 0.2, 1)`
- **几乎无装饰动效**；数据变化用 300ms 数值过渡
- 页面切换用淡入，无位移

#### 优势与风险

**优势**
- 临床可信度最高，医院/医生合作方最易接受
- 数据清晰、信息密度高，复诊整理场景（S5）体验最好
- 开发成本低、组件复用率高、暗色模式容易做
- 中性调性不易出错

**风险**
- ⚠️ **冷灰蓝调会强化"患者 / 医疗 / 仪器"的身份感，加重病耻感** —— 这是本方向最致命的问题。用户每天打开它，等于每天确认一次"我是一个需要被监测的病人"
- ⚠️ 冷灰色对抑郁情绪有轻微的"压抑 / 阴天"暗示，长期使用缺乏情绪回报
- ⚠️ 情感温度不足，用户黏性与自发性打开率低（对"复发预防"这种需要长期坚持的产品是硬伤）
- ⚠️ 与"归途"的温暖叙事严重冲突

#### ⚠️ 四级风险配色（方向 C）

采用**绿色系内的"成熟度"推移**——从新叶到秋禾，隐喻"生长阶段"而非"好坏"：

| 等级 | 名称 | 圆点色 | 文字色 | 浅底 | 形状 |
|------|------|--------|--------|------|------|

| L3 | 关注 | `#C4A279` | `#957350` | `#F7EFE1` | △ |
| L4 | 需要支持 | `#C08A6E` | `#8F6047` | `#F6E8DE` | ◐ |

> ⚠️ 本方向 L1 与 L2 色相极近（绿 → 黄绿），辨识度是本方向最大的技术风险，**形状编码为强制**。

#### 字体方向

- 圆润无衬线，略带手写温度（中文可选圆体/幼圆系衍生，或收笔带圆角的柔性黑体）
- 字重偏轻（Regular / Medium），标题可用更大字号 + 更宽字距制造"舒展感"
- 行高 1.8（三方向中最松）
- 数字用圆润字形，弱化"测量"感

#### 图形语言

- **超大圆角**：24–32px（卡片），16px（按钮），接近"胶囊"
- 有机不规则形状：叶片轮廓、水滴、柔和的不对称弧
- 手绘感描边：线条允许极轻微的自然抖动，非机械直线
- 图标：手绘线性 + 少量柔和填充（填充色为浅底色的加深版）
- 留白最宽松：屏幕边距 24px，模块间距 20px，一屏 2–3 个信息块

#### 图像 / 插画风格

- **柔焦植物微距摄影**（叶脉、露水、苔藓、新芽）为主
- **纸质感手绘插画**为辅（水彩、淡彩、铅笔淡描）
- 无人物面部；可有手部（捧着什么、浇水）
- 插画应保持"成人向的克制"，禁止 Q 版、禁止拟人化笑脸

#### 材质与肌理

- 纸张纹理明显（噪点 6–8%，可叠加纸纤维质感）
- 水彩渐层：颜色边缘带自然扩散
- 手绘阴影：柔和、偏暖、无方向硬边

#### 动效调性

- 时长 300–500ms（三方向中最慢），有机缓动
- 特征动效：**"生长"** —— 进度条像枝条延伸、签到完成时叶片轻微舒展
- 页面切换用缓慢淡入 + 轻微上浮

#### 优势与风险

**优势**
- **去病耻感效果最好**：植物/生长隐喻完全绕开"病人"身份
- 有明确的希望感和正向叙事，长期陪伴的黏性最高
- 温暖度最高，最适合"每日打开"的生活伴侣定位

**风险**
- ⚠️ **插画与植物意象极易滑向"消费级打卡 App"**，削弱临床严肃性——对"复发预防"这种有临床后果的产品，风险很高
- ⚠️ 绿色系风险分级辨识度最低（L1/L2 几乎同色）
- ⚠️ 手绘质感在低龄化与轻佻的边缘："浇水长叶子"的隐喻可能被用户解读为"我的康复被游戏化了"
- ⚠️ 纸张纹理与手绘阴影在移动端小屏上易显脏、显乱

## 3. 推荐主方向

### ✅ 推荐：方向 A「晨光归途」为主干，融合 B 的秩序与 C 的温度

#### 3.1 融合结构

```
┌─────────────────────────────────────────┐
│  骨  架  层  →  方向 A                   │
│  色彩系统 / 留白节奏 / 光线肌理 / 暖砂白  │
├─────────────────────────────────────────┤
│  秩  序  层  →  方向 B（借入）           │
│  8pt 网格 / tabular 数字 / 数据可视化     │
│  服务中心信息密度 / 无装饰动效            │
├─────────────────────────────────────────┤
│  温  度  层  →  方向 C（借入）           │
│  超大圆角 / 有机曲线母题 / 成长型正反馈   │
│  签到完成时的轻微"舒展"动效               │
└─────────────────────────────────────────┘
```

- ✅ **从 B 借**：8pt 严格网格、等宽数字、清晰的数据可视化（折线/雷达）、服务中心的信息密度、严禁装饰动效的自律
- ✅ **从 C 借**：卡片大圆角（20px）、"路径弧线"作为全局图形母题、签到完成时的轻微舒展反馈、有机曲线的使用
- ❌ **不从 C 借**：手绘抖动线、植物插画、超大胶囊圆角（24–32px）、纸张纤维纹理 —— 这些会削弱临床可信度
- ❌ **不从 B 借**：冷灰背景 `#F7F8F8`、直角端点图标、紧凑留白 —— 这些会加重病耻感与压抑感

#### 3.2 为什么 A 最适合"抑郁症复发预防"

| # | 理由 | 说明 |
|---|------|------|
| 1 | **晨光是唯一诚实的意象** | 它同时承认"暗还在"和"光已来"。康复期用户的真实体验正是如此——不是"痊愈了"，而是"今天比昨天亮一点"。任何纯光明的视觉（C 的嫩芽）都是否认，任何纯冷静的视觉（B 的静水）都是疏离 |
| 2 | **暖调是低能量状态的安全色** | 抑郁状态伴随情绪低落与常见的光敏感。冷灰蓝会强化低落（B 的致命伤），高饱和会引发刺激（C 的风险）。暖砂褐同时提供"体温感"和"低刺激" |
| 3 | **暖砂白 `#FAF7F2` 直接解决生理不适** | 纯白 #FFFFFF 在 OLED 屏上夜间刺眼；暖砂白降低蓝光比例，是生理层面的体贴，不只是审美 |
| 4 | **"归途"与视觉天然同构** | 路 + 光 + 上海清晨 = 品牌名的字面解释。视觉资产的叙事成本几乎为零，用户不需要被告知就能读懂 |
| 5 | **中性暖调兼容两个极端场景** | 危机干预页（需要稳）和每日签到（需要轻）共用一套底色即可，不需为不同模块切换色彩体系，降低认知负荷 |
| 6 | **在地性有具体落点** | 上海清晨的弄堂、梧桐、江面——不是抽象的"关怀"，是"这家公司真的知道我在哪个城市" |

## 5. Logo / 品牌标识概念（3 个）

> 通用适配原则（App 图标 40–60px 显示场景）：
> ① **单一视觉焦点** —— 小尺寸下只保留一个"眼睛会去的地方"
> ② **线条 ≥ 2px**（@1x 下不小于 1.5px），避免细线在压缩时消失
> ③ **不依赖渐变细节**，纯色版必须成立
> ④ 在 `#FAF7F2` 暖砂白底上对比度足够（避免使用 `#E8A87C` 微光橙作为主形）

---

### 概念 1 ｜「归途线」Path Line ⭐ 推荐作为品牌主标

**图形描述**
一条从左下起、向右上延伸的柔和缓弧，2.5px 暖砂褐 `#A97C5F` 描边，圆头端点。弧线在约 60% 处有一个极轻微的向上转折（暗示"路有起伏但方向不变"）。弧线末端逐渐变细，并终止于一个**实心圆点**，圆点使用微光橙 `#E8A87C`，直径约为弧线长度的 1/8。

**隐喻**
- 弧线 = 回家的路 / 康复之路（"归途"字面）
- 转折 = 复发与波动是被预期的，不改变方向
- 末端光点 = 光在前方，且已经亮着
- 整体外形的起笔与竖势隐含「申」字的笔意（上海 = 申）

**适配性**
- ⭐⭐⭐⭐⭐ 40px 下：弧线 + 光点两个元素，清晰可辨
- 纯色版（单色 `#A97C5F`）成立，光点改为实心弧线末端
- 反白版（白线 + 白点，深底）成立
- **风险**：光点颜色 `#E8A87C` 在暖白底上对比偏低 → 解决：App 图标场景光点改用 `#C98A5E`（加深版微光橙）

---

### 概念 2 ｜「窗与光」Window Light ⭐ 推荐作为 App 图标

**图形描述**
一个圆角方形（圆角约为边长的 22%）的窗框，2.5px 暖砂褐描边，**四边不闭合**：右下角留出约 1/5 边长的开口。窗框内部有一束光以 12% 透明度的暖金渐层向右下溢出到框外，形成柔和的光晕。窗框内部左下角有一个极小的实心点（可理解为"人在窗内"，尺寸极小不做具象）。

**隐喻**
- 窗 = 出口、视野、不是封闭的房间
- 开口 = 门没关死，随时可以出去（对危机状态的暗示）
- 溢出的光 = 光不是被关住的，它溢出来照到外面
- 不闭合 = 过程未完成，还在路上

**适配性**
- ⭐⭐⭐⭐⭐ 40px 下：圆角方 + 光晕，形状识别度最高（**方形轮廓在小尺寸下比曲线更容易识别**）
- 纯色版：窗框 + 右下开口 + 框内 20% 灰填充，成立
- 反白版成立
- **这是三个概念中 App 图标小尺寸可读性最好的一个**

---

### 概念 3 ｜「双弧托举」Two Arcs

**图形描述**
两条上下相对的柔和弧线：下方弧线开口向上（像一个托起的掌心），上方弧线开口向下，两条弧线之间"托住"一个实心圆点（微光橙）。整体外形接近抽象化的「归」字结构，也像两只手捧着一颗光。弧线 2px，圆点直径约为整体高度的 1/6。

**隐喻**
- 双弧 = 托底、被接住、不是独自在走
- 圆点 = 你（被托着的那个人），也是光
- 整体 = "有人同行"这一品牌承诺的图形化

**适配性**
- ⭐⭐⭐⭐ 40px 下：双弧 + 圆点，圆点是明确的视觉锚点
- 纯色版成立（圆点与弧线同色）
- **风险**：两条弧线在小尺寸下容易糊成一个"椭圆"，需加大弧线间距（≥ 整体高度的 1/4）并加粗至 2.5px
- **气质最温暖**，但"手捧"的具象感略强，可能在医院渠道显得不够专业

## 6. 全局视觉禁忌清单（Red Lines）

以下为**一票否决项**，任何环节（含后续 image-creator 出图、UI 实现、文案）均不得违反：

| # | 禁忌 | 原因 |
|---|------|------|
| 1 | 纯色相红 `#FF3B30` / `#E03A2F` 及任何"警报红" | 触发灾难化恐慌 |
| 2 | 感叹号弹窗、红色 Badge、闪烁、脉动、抖动 | 高唤醒刺激 |
| 3 | 纯白 `#FFFFFF` 作为大面积背景 | 光敏感、夜间刺眼 |
| 4 | 纯黑 `#000000` 作为暗色模式底 | 压抑、加重低落 |
| 5 | 高饱和色（饱和度 > 60% 的任何大面积色块） | 抑郁状态对高饱和极度敏感 |
| 6 | 火焰 🔥 / 连续天数 / 排行榜 / 徽章 / 成就系统 | 游戏化 = 轻佻 + 中断即惩罚 |
| 7 | 卡通笑脸、拟人化器官、Q 版插画 | 幼稚化、不尊重 |
| 8 | 宋体/衬线体做正文 | 病历感、机构压迫 |
| 9 | 表情符号作为主要信息载体（如用 😢 表示心情差） | 强迫用户在低能量时做情绪表演 |
| 10 | 深渊、坠落、锁链、笼子、暴雨、乌云、枯树、迷宫、破碎镜子 | 触发性意象 |
| 11 | "必须 / 应该 / 建议你立即" 类命令式文案 | 权威压制 |
| 12 | 二次确认弹窗（尤其危机干预流程） | 在危机时刻增加操作摩擦 = 致命 |
| 13 | 自动轮播、强制引导、首次打开的 5 页 onboarding | 低能量状态下的认知负荷 |
| 14 | 社交分享、公开排行榜、任何形式的公开可见 | 病耻感 |
